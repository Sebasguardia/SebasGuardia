1. Crea un repositorio con el mismo nombre de tu usuario de GitHub.
2. Ejemplo:

```bash

```

3. Dentro del repositorio crea un archivo:

```bash
README.md
```

4. Copia todo este contenido.

5. Reemplaza:

* `TU_USERNAME`
* `TU_REPO_1`
* `TU_REPO_2`
* `TU_CORREO`

6. Haz commit y automáticamente aparecerá en tu perfil.
